# Reference ROM Disassemblies

This directory contains reference disassembly files collected from the
public [ZXSpectrumVault/rom-disassemblies](https://github.com/ZXSpectrumVault/rom-disassemblies)
repository at the revision recorded below. Their source content is retained for
reference, with the project notice added where required by the repository gate;
they are not new project source code and retain their upstream copyrights and
applicable terms.

## Included Scope

- `spectrum-48k/`: Sinclair ZX Spectrum 48K and Interface 1 disassembly sources.
- `spectrum-128k/`: Sinclair ZX Spectrum 128K disassembly sources and annotation files.

The source repository states that Sinclair ROM copyright belongs to Amstrad PLC,
with non-commercial redistribution permitted, and credits the ROM and disassembly
authors in its upstream README. Interface 1 material is included as a separately
identified reference and remains subject to its applicable Sinclair Research
copyright. +2, +3, ZX80, and ZX81 material is not included in this initial corpus.
