# ZX-UX technical references

The ZX-UX builders use the committed project sources. These public links
are reference material for understanding the Sinclair ZX Spectrum and Z80.
External manuals and reference sites are not part of the distribution.

- [48K Spectrum ROM disassembly](https://skoolkit.ca/disassemblies/rom/),
  by Richard Dymond and contributors.
- [Spectrum ROM disassembly sources](https://github.com/ZXSpectrumVault/rom-disassemblies),
  including 48K and 128K material.
- [48K technical information](https://worldofspectrum.org/faq/reference/48kreference.htm)
  at World of Spectrum.
- [128K technical information](https://worldofspectrum.org/faq/reference/128kreference.htm)
  at World of Spectrum.
- [Z80 CPU User Manual](https://www.zilog.com/docs/z80/um0080.pdf)
  from Zilog.

Each reference keeps its own copyright and license. A public download link
is not permission to copy someone else's manual into a ZX-UX release.
