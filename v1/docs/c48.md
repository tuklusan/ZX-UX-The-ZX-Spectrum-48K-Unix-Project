# C48 Version-1 Language Contract

This document is the Phase-11 working language contract derived from immutable
ZX-UX Architecture REV16 Section 25. REV16 remains authoritative. The checked-in
binary `docs/04-C48 Language Specification Rev 0.11.docx` and the pinned Python
SDK are mandatory comparison inputs; neither may override REV16.

## Supported language surface

C48 version 1 supports exactly these language families: `void`, `char`,
`unsigned char`, `short`, `unsigned short`, `int`, `unsigned int`,
five-byte `float`, pointers, one-dimensional arrays, functions, restricted
fixed-argument prototypes, locals, globals, file-scope static storage, `extern`,
`if/else`, `while`, `do/while`, `for`, `break`, `continue`, `return`,
`sizeof`, string literals, character literals, simple constant scalar
initializers, one-dimensional constant array initializers, and casts among
integer scalar types and between integer scalar types and `float`.

Version-1 operators are `=`, `+ - * / %`, `++ --`, `<< >>`,
`< <= > >= == !=`, `& | ^ ~`, `&& || !`, address-of/dereference
`& *`, indexing/call `[] ()`, and unary `+ -`.

Compound assignments, the conditional `?:` operator, and the comma operator
are deferred.

The following are not version-1 C48 features unless a later canonical
architecture revision says otherwise: distinct `double`, `long long`,
variable-length arrays, complex initializers, variadic functions, function
pointers, `switch/case`, `struct/union`, complex preprocessor macros,
optimizer passes requiring large IR, and full ISO C conformance. `long` is
unsupported.

## Exact data model

| Type | sizeof | alignment |
| --- | ---: | ---: |
| `char`, `unsigned char` | 1 | 1 |
| `short`, `unsigned short` | 2 | 2 |
| `int`, `unsigned int` | 2 | 2 |
| pointer | 2 | 2 |
| `float` | 5 | 1 |

Plain `char` is unsigned. `signed char` is not a distinct version-1 type.
Arrays have no inter-element padding beyond element `sizeof`; array stride is
exactly `sizeof(element)`. `sizeof` yields `unsigned int`. Signed
`short` and `int` are two's-complement.

Integer addition, subtraction, multiplication, unary minus and left shift wrap
modulo operand width. Signed division truncates toward zero and signed remainder
has the dividend's sign. Signed right shift is arithmetic; unsigned right shift
is logical. Shift counts use the low 3 bits for 8-bit values and low 4 bits for
16-bit values. Pointer arithmetic scales by pointed-to `sizeof`; subtraction
within the same array/object yields a signed 16-bit element count.

## Functions and entry points

Prototypes use only supported scalar/pointer types and a fixed argument count.
Prototype and definition types match exactly. Program entry is exactly
`int main(void)` or `int main(int argc, char **argv)`.

The sole externally linkable calling convention is `C48_REGCALL`: the first
three 16-bit scalar/pointer slots use HL, DE and BC; remaining slots are
right-to-left 16-bit stack words. Eight-bit `char` arguments are zero-extended.
SP is even at every C48 call boundary. Float arguments are pointers to
caller-owned five-byte values. Float returns use a hidden first result pointer
in HL and shift user arguments to DE, BC, then stack.

AF, BC, DE and HL are caller-clobbered. IX is callee-preserved when used. IY is
OS/ROM-reserved. The alternate register bank is OS-private.

## Preprocessor boundary

Version 1 supports object-like `#define`, one-level local
`#include "name"`, and built-in `#include <c48.h>`. Macro functions,
recursive include, conditional preprocessing, token pasting, stringification,
and a full ISO preprocessor are deferred.

## Source and output contract

Identifiers are case-sensitive and at most 15 visible characters. The native
compiler command is lower-case `cc`, consumes one C-typed input object, and
emits REV16 OBJ1 through an atomic temporary-object/rename transaction. The
native backend emits Z80 machine code; the Python SDK's C48B1 host format is not
OBJ1, MEX1, or target code.

The compiler is streaming and memory-bounded: it must not require a whole-program
AST. Expression trees are bounded and released promptly. The complete native
compiler process-owned live footprint has a release target of at most 20 KiB.

## Authority rule

Where REV16, this document, the DOCX, the pinned SDK, or later native behavior
disagree, REV16 controls. A discrepancy is recorded and resolved; it is never
silently copied.
