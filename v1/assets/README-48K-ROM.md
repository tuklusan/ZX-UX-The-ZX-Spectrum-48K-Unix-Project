## Historical Amstrad redistribution permission

In August 1999, Cliff Lawson of Amstrad plc publicly described Amstrad's
policy for Sinclair Spectrum ROM use by emulator authors. Amstrad permitted
emulator writers to redistribute Spectrum ROM images provided the copyright
messages were not altered, and requested acknowledgement that:

> Amstrad have kindly given their permission for the redistribution of their
> copyrighted material but retain that copyright.

The same statement made clear that the ROM code itself should not be charged
for separately. Emulator authors could charge for their own emulator code so
long as they were not charging for the Amstrad/Sinclair ROM portions. The
statement also allowed modified ROM images subject to the same copyright
proviso, and identified the Spectrum 48/128 and Amstrad-produced + models as
within that permission.

This repository includes the unmodified 48K ROM only for hobbyist,
emulation, compatibility, and conformance/reference work. No fee is charged
for the ROM image itself.
