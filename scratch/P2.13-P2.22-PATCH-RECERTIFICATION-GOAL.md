## Temporary goal

Construct and execute one bounded patch workflow that:

1. starts from the historical P2.13 integration defect;
2. changes only the SjASMPlus preprocessor marker from:
   `ZX48_P2_13_LINKS_EMITTED EQU 1`
   to:
   `    DEFINE ZX48_P2_13_LINKS_EMITTED 1`;
3. carries that inherited correction forward through the exact historical checkpoints P2.14–P2.22;
4. at every reconstructed step, runs that step's build/test contract plus relevant predecessor regressions;
5. at every reconstructed step, proves from emitted bytes/symbols that the production spawn path selects:
   `call zx48_process_link_child`;
6. fails if the legacy ELSE publication path is emitted instead;
7. keeps the P2.22 allocator-normalization defect separate from the P2.13 composition defect;
8. applies the allocator normalization only at P2.22:
   zero the merged-away extent start bytes at `(ix+4)` and `(ix+5)` before zeroing `(ix+6)` and `(ix+7)`;
9. requires P2.22 to pass only with both independent repairs present;
10. records exact historical commit, reconstructed commit, tree, process blob, memory blob, build/test result, regression result, and emitted-code proof for every replayed step.

## Preserved lesson

Source presence is not integration proof.

Any staged assembly feature selected by `IFDEF` or `IFNDEF` must have an explicit assembler-semantics probe and emitted-code/runtime reachability proof in the production composition that consumes it. A source grep, isolated helper fixture, or successful assembly of the helper routine alone is insufficient.

For P2.13 specifically, the workflow must prove all of the following together:

- SjASMPlus treats `EQU` as not satisfying the relevant `IFDEF`;
- `DEFINE` inside the emitter does satisfy the `IFDEF`;
- the production spawn composition emits exactly one `CALL zx48_process_link_child` in the spawn/rollback region;
- the legacy ELSE publication sequence is not the selected production path.
